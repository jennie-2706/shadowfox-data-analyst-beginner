Titanic Survival Analysis
Project Overview

This project analyzes the Titanic dataset to understand passenger survival patterns using Python and data analysis techniques.

Tools Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Excel

Analysis Performed
Data cleaning and preprocessing
Missing-value handling
Passenger and survival statistics
Survival analysis by passenger class
Survival analysis by gender
Age-group analysis
Family-size analysis
Fare analysis
Data visualization
Dashboard creation

Key Findings
The analysis shows that survival varied considerably based on passenger class, gender, age group, and family size.
